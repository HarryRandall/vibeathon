# Vibeathon

Not a single line of code here was properly written or reviewed, and the quality is probably atrocious. The final product was still decent for roughly 5 hours of work and limited tokens.

## What We Built

Built at the ANU AI Buildathon 2026 by a group of 4, `Vibeathon` is an AI-powered Canvas companion with:

- course import from Canvas
- a study assistant
- AI-generated practice quizzes

We ended up placing **2nd** out of roughly **34 teams**.

## Stack

Built with `Next.js`, `TypeScript`, `Tailwind`, `OpenRouter`, `Supabase`, and a Canvas data ingestion pipeline, then deployed on `Vercel`.
