# Vibeathon

Not a single line of code here was properly written or reviewed, and the quality is probably atrocious. The final product was still decent for roughly 5 hours of work and limited tokens.

Built at the ANU AI Buildathon 2026 by a group of 4: an AI-powered Canvas companion with course import, a study assistant, and AI-generated practice quizzes.

Tech-wise, this was built with Next.js, TypeScript, Tailwind, OpenRouter, Canvas data ingestion, and Supabase, and deployed on Vercel.

We ended up placing 2nd out of roughly 34 teams.
